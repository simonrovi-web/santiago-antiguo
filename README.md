# Santiago Antiguo

Paseo en primera persona por el centro de Santiago de Chile a comienzos del siglo XX: Plaza de Armas, Catedral, Portales, La Moneda y Estación Mapocho. Funciona en el navegador del celular o del computador, sin instalar nada.

**Jugar:** https://simonrovi-web.github.io/santiago-antiguo/

- Celular: lado izquierdo de la pantalla para caminar, lado derecho para mirar.
- Computador: clic para mirar con el mouse, WASD para caminar, Shift para correr, Espacio para saltar.

Ciudad generada proceduralmente en Blender y exportada a glTF; motor en Three.js con colisión por three-mesh-bvh.
